4. Onde a diferença acontece no código

⚠️ Com o Bug (Mono.empty)

public Mono<RightsCard> getCard(String id) {
  return client.fetch(id)
    .onErrorResume(ex -> Mono.empty());
}

✅ Com o Fix (Mono.just com objeto)

public Mono<RightsCard> getCard(String id) {
  return client.fetch(id)
    .onErrorResume(ex ->
       Mono.just(RightsCard.empty()));
}
